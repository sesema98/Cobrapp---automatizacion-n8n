Flujo de Trabajo CobrApp

Registro automatico de pagos Yape o Plin con Telegram, n8n y Python OCR

Automatizacion activa con Telegram
1

Usuario envia captura

El cliente envia una imagen de Yape o Plin al grupo de Telegram del negocio.

  • Foto del comprobante
  • Grupo de pagos
  • Bot agregado al grupo
2

n8n recibe el evento

El nodo Telegram Trigger escucha el grupo y detecta si el mensaje trae una imagen.

  • Valida foto o documento
  • Obtiene el file_id
  • Descarga la imagen
3

API Python procesa OCR

n8n envia la imagen a FastAPI. Python mejora la imagen y extrae texto con Tesseract OCR.

  • OpenCV preprocesa
  • pytesseract lee texto
  • Regex extrae datos
4

Registro y respuesta

La API registra el pago en Excel y n8n envia una confirmacion automatica al grupo.

  • Guarda en pagos.xlsx
  • Detecta duplicados
  • Confirma por Telegram

Flujo interno en n8n

Telegram Trigger Recibe el mensaje enviado al grupo de Telegram.
IF - Tiene imagen Comprueba si el mensaje contiene una foto o imagen como documento.
Descargar imagen Usa el file_id para obtener el archivo real desde Telegram.
HTTP - OCR Envia el binario a la API FastAPI mediante multipart/form-data.
IF - Pago valido Evalua si la API encontro monto, tipo y numero de operacion.
Confirmar pago Responde al grupo con nombre, monto, tipo, operacion y estado.
Imagen invalida Informa al grupo cuando no se pudo reconocer un pago valido.

Procesamiento en la API Python

Endpoint principal

POST /procesar-imagen Content-Type: multipart/form-data Campo: file

Datos extraidos

  • Fecha y hora
  • Nombre del pagador
  • Monto en soles
  • Tipo: Yape o Plin
  • Numero de operacion

Almacenamiento

Los datos se guardan en pagos/pagos.xlsx con estado Registrado, Duplicado, No registrado o Excel bloqueado.

Pago valido

Si la API detecta datos suficientes, registra el pago en Excel. Luego n8n envia una confirmacion al grupo con el resumen del comprobante.

Pago invalido o duplicado

Si faltan datos o la imagen no corresponde a un pago, se informa al grupo. Si el numero de operacion ya existe, se marca como duplicado.

Reporte diario

A

Schedule Trigger

n8n ejecuta el flujo de reporte a una hora programada.

B

GET /reporte

FastAPI calcula pagos del dia y total recaudado desde el Excel.

C

Telegram envia resumen

El bot publica en el grupo la cantidad de pagos y el total del dia.
